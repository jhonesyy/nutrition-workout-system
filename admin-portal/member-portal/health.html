Health Integration

What this page can and cannot do

Apple HealthKit and Google Health Connect only work inside native iOS/Android apps with user permission. This web member portal cannot read those APIs from Safari/Chrome. Device data must be sent by the NutriFit mobile app to POST /api/health/sync.

Here you can manually sync steps and active calories (source = manual), and view history stored in the same database the mobile apps use.
